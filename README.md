# AiXel Visual Melody

AiXel Visual Melody is a premium creative studio where music becomes living visual art.

**Tagline:** Transform Your Music Into Living Visuals.

## Core Philosophy

Music becomes Light.

Music becomes Motion.

Music becomes Emotion.

## Approved Workflow

The approved product workflow is:

Home
→ Analyze
→ Create
→ Preview
→ Export

Settings is accessible from every screen.

1. Cosmic Waves
2. Jazz Geometry

4. Frequency City
5. Minimal Album Art
6. Neon Velvet

## Design Checkpoint

This repository checkpoint is design-only.

It preserves the structure and source locations for the approved **AiXel Visual Melody - Master Design Package V1.0**. It does not convert the app to React, does not add unrelated product features, and does not begin the real audio-analysis or video-rendering engine.

The approved Claude Design package remains the visual source of truth.

## V0.1 Functional Visual Shell

The React + Vite + TypeScript shell translates the approved visual direction into a navigable application surface:

- Home, Analyze, Create, Preview, Export, Settings, and Design System screens.
- Settings remains accessible from every screen.
- The six approved visual engines are present.
- Create includes engine-reactive theming for accent color, preview surface, and radius.
- All analysis, preview, and export values are representative sample data only.

Run locally with:

```bash
npm install
npm run dev
```
