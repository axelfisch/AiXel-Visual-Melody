# Visual Engines Spec

The approved AiXel Visual Melody design package defines six visual engines:

1. Cosmic Waves
2. Jazz Geometry
3. Liquid Colors
4. Frequency City
5. Minimal Album Art
6. Neon Velvet

## Current Scope

This checkpoint documents the approved engine names only.

No real audio-analysis engine, visual synthesis engine, or video-rendering engine begins in this checkpoint.
